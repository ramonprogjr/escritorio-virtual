Análise 2026-06-23. Responde "inteligência por trás dos agentes, IA-first, integração Anthropic".

**Criação/config de agente:** tabela [hub_agente_identidade]. Campos que definem o agente: `agente_slug`(único), `nome`, `cargo`(valida `hub_cargos_catalogo`), `persona`/`tom_voz`/`estilo_comunicacao`/`system_prompt_base`/`nunca_dizer`/`sempre_dizer`/`pode_fazer`, **3 colunas de modelo** `modelo_padrao`/`modelo_critico`/`modelo_alto_valor` (constraint `chk_modelo_valido`), `modo_operacao`(`canal_whatsapp`|`jobs_internos`), `motor_ferramentas_habilitado`+`uso_ferramentas_ia`, `uazapi_instance_*`. UI: wizard em [app/crm/agentes](C:/Users/wende/Documents/escritorio-virtual-ramon/app/crm/agentes/page.tsx) (Cargo→Identidade→Personalidade→RAG→Ferramentas→Playbook→Canal). POST cria o agente E provisiona um ciclo em `hub_ciclos_ia` com `configuracoes.dispatch={api,ciclo}` ([lib/ciclos-dispatch.ts](C:/Users/wende/Documents/escritorio-virtual-ramon/lib/ciclos-dispatch.ts)).

**Engine (cérebro):** [lib/ia/engine.ts](C:/Users/wende/Documents/escritorio-virtual-ramon/lib/ia/engine.ts) `processarMensagem` (10 etapas): router de agente → autonomia (atendimento WhatsApp tem bypass de aprovação) → histórico → prompt (`lib/ia/prompt-builder.ts`) → LLM (±tools) → grava `hub_prompt_logs` → extrai memórias (lead+agente) por LLM → enfileira resposta. Memória: janela `HUB_ENGINE_HISTORICO_MENSAGENS`(10), resumo auto ≥`HUB_CONVERSA_RESUMO_APARTIR`(30) via `MISTRAL_MEMORY_MODEL`, TTL de sessão `HUB_SESSAO_CONVERSA_TTL_HORAS`(12h).

**Ciclos diretor/gerente/atendente** (`app/api/ciclos/*`): são **regras DETERMINÍSTICAS, não chamam o LLM de conversa** — diretor(tráfego CPC/análises), gerente(relatório manhã/supervisão por palavras de reclamação), atendente(followup/SLA). Orquestrados por cron [app/api/cron/dispatch-ciclos](C:/Users/wende/Documents/escritorio-virtual-ramon/app/api/cron/dispatch-ciclos/route.ts). Único que usa LLM: `lib/ia/ml.ts`.

**PROVEDOR LLM — realidade: MISTRAL-FIRST.** Sentinel `"mistral"` gravado nos agentes → expande para `MISTRAL_MODEL`(default `mistral-small-latest`), em [lib/ia/hub-model-defaults.ts](C:/Users/wende/Documents/escritorio-virtual-ramon/lib/ia/hub-model-defaults.ts). Mistral cobre: chat (`lib/ia/mistral-chat.ts`), **function-calling/tools** (`lib/ia/mistral-chat-tools.ts` + `llm-completion-tools.ts`), Agents API (`lib/mistral/sync-hub-agent.ts`), embeddings RAG (`mistral-embed`), transcrição de áudio, sugestões "smart".

**ANTHROPIC: já integrado e funcional, porém SECUNDÁRIO e hoje DORMENTE** (`ANTHROPIC_API_KEY` vazia). `@anthropic-ai/sdk` é usado de verdade em: (1) [lib/ia/llm-completion.ts](C:/Users/wende/Documents/escritorio-virtual-ramon/lib/ia/llm-completion.ts) — wrapper que roteia p/ Anthropic só se modelo for `claude-*` E houver chave (com fallback cruzado Mistral↔Claude); (2) `lib/ia/ml.ts` — ciclo ML com `claude-haiku-4-5` **hardcoded, sem fallback** (endpoints `/api/ml/*` quebram sem a chave); (3) fallback dos wizards "Gerar com IA". Google AI (Gemini) é opcional/nicho (`lib/ia/gemini-text.ts`).

**GAP para tornar Anthropic first-class:** (1) setar `ANTHROPIC_API_KEY`; (2) trocar `modelo_padrao/critico/alto_valor` dos agentes p/ id `claude-*` (respeitar `chk_modelo_valido`); (3) **construir caminho de TOOLS para Anthropic** — o gate `podeToolsMistral` no engine exige `isMistralFamilyModelId`, então **agente Claude perde ferramentas**; precisa de um `llm-completion-tools` no formato tool-use da Anthropic; (4) migrar `ml.ts` hardcoded p/ wrapper/fallback; (5) Agents API + embeddings RAG + transcrição são Mistral-only (sem equivalente Anthropic). Ao IMPLEMENTAR Anthropic, consultar a skill `claude-api`; ids atuais: `claude-opus-4-8`, `claude-sonnet-4-6`, `claude-haiku-4-5`.

**IA-first (a IA sugere, humano decide):** flags em [lib/crm/feature-flags.ts](C:/Users/wende/Documents/escritorio-virtual-ramon/lib/crm/feature-flags.ts) — `CRM_IA_AUTO_CADASTRO=false`(off), `CRM_DISTRIBUICAO_AUTO=true`, `CRM_PROXIMA_ACAO_OBRIGATORIA=false`. Encaminhamento: `lib/crm/sugerir-encaminhamento-auto.ts` cria `hub_encaminhamentos` com `status=aguardando_validacao,sugerido_ia:true` → humano aprova → envia. Freios: `hub_autonomia_matriz` (`exige_aprovacao`,`limite_autonomia_brl`), `lib/ia/guardrails.ts`, fila `hub_aprovacoes`. Tools dos agentes em `lib/hub/agente-ferramentas-registry.ts` (hub_lead_*, hub_atualizar_lead, hub_crm_criar_cadastro, custom). Triagem determinística "Maria/Mari" é só playbook — nome do agente é configurável, não spec.
