# Índice dos INSUMOS DO DONO — visão estratégica (para não nos perdermos)

> Tudo que o dono ensinou, organizado. Régua de produto: o sistema retira **dores reais**; a tela mostra a **cura dos medos**; honesto e justo; o Hub é juiz; nada se perde.

## Visão & princípios
- **[portal-do-cliente-e-medos.md](portal-do-cliente-e-medos.md)** — o cliente tem usuário próprio (dashboard-first); os **5 medos** (atrasar/não acabar/não saber/ser enganado/perder dinheiro) → a tela mostra a **cura**. A alma do produto.
- **[integracao-contas-negocio-spine-logs.md](integracao-contas-negocio-spine-logs.md)** — o **negócio** (origem = venda do imóvel) é a espinha que interliga as contas; **"nada se perde"** (log de tudo, Hub recupera); visão curada por papel (anti-poluição); mensageria.

## Financeiro & confiança
- **[modelos-contrato-e-escrow.md](modelos-contrato-e-escrow.md)** — **2 modelos imutáveis** (administração=unitário / preço fechado=totais) que bifurcam o financeiro; **ESCROW** (paga só com aprovação dupla arquitetura+Hub); engenharia auditorial ("somos juízes").

## Marketplace / rede / "iFood da construção"
- **[servicos-cadeia-contratacao-monetizacao.md](servicos-cadeia-contratacao-monetizacao.md)** — ofícios (marcenaria/vidraçaria/...) + hierarquia de contratação (arq→eng→prestadora→mão de obra); **spread em cada elo**; mão de obra = commodity raro.
- **[ifood-construcao-pedidos.md](ifood-construcao-pedidos.md)** — venda de materiais/eletros/ferramentas + aluguel; **pedidos compartilhado**; fluxo (voz/IA→geo→preço da base→aprovação→entrega→tracking); spread por produto; meu veredito: preditivo + asset-light + spread honesto.
